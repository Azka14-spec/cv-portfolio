## 💡 Tips

1. **Save Certificates:** Store images or PDFs of your certificates
2. **Name Clearly:** Use format: `YYYY-MM-DD_CertificateName.pdf`
3. **Add Descriptions:** Create a `.md` file with details about each achievement
4. **Keep Organized:** Use subfolders for different types of achievements
5. **Update Regularly:** Add new achievements as soon as you get them
