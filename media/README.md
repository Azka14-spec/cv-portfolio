# 📸 Media & Proof Files

Store certificate images, medal photos, event photos, and other proof files here.

## 📂 Structure

```
media/
├── certificates/          # Certificate images/PDFs
├── medals/               # Medal photos
├── events/               # Event participation photos
├── awards/               # Award photos
└── [other-proof]/        # Other supporting documents
```

## 📝 Naming Convention

Use this format for organizing files:
- `YYYY-MM-DD_AwardName.jpg` or `.pdf`
- Example: `2024-03-15_MusicCompetition.jpg`

## 📸 What to Upload

- [ ] Music Competition Certificate
- [ ] School event certificates
- [ ] Running event proof/medal
- [ ] Soccer event proof/medal
- [ ] MUN certificate or participation proof
- [ ] Cultural Exchange Program certificate
- [ ] Award photos
- [ ] Event participation photos
- [ ] Other achievement proofs

---

## 💡 Tips

1. **Keep Organized:** Sort by type (certificates, medals, photos)
2. **High Quality:** Use clear, readable images
3. **Backup:** Keep digital copies in multiple places
4. **Label Clearly:** Name files with dates and names
5. **PDF When Possible:** Convert certificates to PDF for archival
